# GOLF LESSON — 왕초보에서 90타 깨기까지

골프 입문부터 90타 깨기까지, 두 권의 교재를 하나로 담은 **인터랙티브 골프 레슨 대시보드**입니다.

## 🔗 라이브 데모
> 배포 후 URL: `https://uxuiyoung-dot.github.io/golf-lesson/`

## 구성
- **PART I · 입문** — 골프의 역사, 코스의 구성, 플레이·경기 방법, 골프 용구, 용어 사전, 코스 예의, 스윙 7단계
- **PART II · 90타 깨기** — 가세 히데키의 실전 비결 97가지 (스윙 기초·비거리·쇼트게임·기술샷·스코어 관리)

## 특징
- 좌측 사이드바 내비게이션 + 콘텐츠 라우팅(해시 기반) 구조의 **대시보드형 UX**
- 벤토 그리드 홈: KPI · 부문별 비결 진행도 · 오늘의 비결 · 스윙 타임라인 · 용어 빠른 검색
- 비결/용어 통합 검색, 카테고리 필터, 카드 펼침 인터랙션
- 폰트: **Pretendard** · 아이콘: 인라인 SVG 라인 아이콘
- 의존성 없는 단일 HTML 파일 (외부 리소스는 Pretendard 폰트 CDN 하나)

## 실행
`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드 과정이 없습니다.

## 출처
- 골프교재 1 「왕초보에서 90타 깨기까지」
- 골프교재 2 「히데키의 90타를 깨기 위한 비결」 (가세 히데키)
